# Document Helper

Work through a document task in five passes.

## Steps

1. Read the source document in full. If it is a PDF, extract the text first.
2. Identify the task: summarize, restructure, proofread, or convert.
3. Apply the change to a copy. Never overwrite the original.
4. Save the result as `<name>.revised.md` next to the source.
5. Report what changed in a short bulleted list.

## Conventions

- Keep headings and numbering from the source unless the task says otherwise.
- Preserve links, tables, and code blocks exactly.
- Write the output as plain Markdown.

## Self-check

- The output file exists and opens.
- Every section of the source appears in the output, or is listed as dropped.
